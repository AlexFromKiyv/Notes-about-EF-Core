# Завантаження пов'язаних даних

Entity Framework Core дозволяє використовувати властивості навігації у вашій моделі для завантаження пов'язаних сутностей. Існує три поширені шаблони O/RM, що використовуються для завантаження пов'язаних даних.

* Оперативне завантаження означає, що пов'язані дані завантажуються з бази даних як частина початкового запиту.

* Явне завантаження означає, що пов'язані дані явно завантажуються з бази даних пізніше.

* Ліниве завантаження означає, що пов'язані дані прозоро завантажуються з бази даних під час звернення до властивості навігації.
